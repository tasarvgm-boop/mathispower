1 Πρόσθεση ρητών αριθμών

1.1 Άθροισμα δύο ρητών αριθμών (Ομόσημων και Ετερόσημων)

Θεωρία και Ορισμοί

Ρητός αριθμός είναι κάθε αριθμός που μπορεί να πάρει τη μορφή κλάσματος \(\dfrac{a}{β}\), όπου ο αριθμητής \(a\) είναι ακέραιος και ο παρονομαστής \(\beta\) φυσικός αριθμός διάφορος του μηδενός.

Η πρόσθεση ρητών είναι μια εσωτερική πράξη, δηλαδή το άθροισμα δύο ρητών είναι πάντα ρητός αριθμός.

Κανόνες και Ιδιότητες

  1. Ομόσημοι ρητοί: Για να προσθέσουμε δύο ομόσημους ρητούς (ίδιο πρόσημο), προσθέτουμε τις απόλυτες τιμές τους και στο αποτέλεσμα βάζουμε το κοινό τους πρόσημο.

  2. Ετερόσημοι ρητοί: Για να προσθέσουμε δύο ετερόσημους ρητούς (διαφορετικό πρόσημο), αφαιρούμε τη μικρότερη απόλυτη τιμή από τη μεγαλύτερη και στο αποτέλεσμα βάζουμε το πρόσημο του ρητού με τη μεγαλύτερη απόλυτη τιμή.

  3. Αντίθετοι ρητοί: Το άθροισμα δύο αντίθετων ρητών είναι πάντοτε ίσο με το μηδέν (\(a + (-a) = 0\)).

  4. Ουδέτερο στοιχείο: Το μηδέν είναι το ουδέτερο στοιχείο της πρόσθεσης (\(a + 0 = a\)).

Παραδείγματα

  1. \((+5) + (+3) = +8\) (Ομόσημοι: \(5+3=8\)).
  2. \((-7) + (-4) = -11\) (Ομόσημοι: \(7+4=11\), κοινό πρόσημο \(-\)).
  3. \((+10) + (-3) = +7\) (Ετερόσημοι: \(10-3=7\), πρόσημο του \(+10\)).
  4. \((-15) + (+5) = -10\) (Ετερόσημοι: \(15-5=10\), πρόσημο του \(-15\)).
  5. \(\dfrac{3}{5} + (-\dfrac{3}{5}) = 0\) (Αντίθετοι ρητοί).

1.2 Άθροισμα πολλών ρητών αριθμών (Ομόσημων και Ετερόσημων)

Θεωρία και Ορισμοί

Άθροισμα πολλών ρητών αριθμών, δοσμένων με ορισμένη σειρά, είναι ο αριθμός που προκύπτει αν προσθέσουμε τον δεύτερο στον πρώτο, στο αποτέλεσμα τον τρίτο, και ούτω καθεξής. Στην πράξη, μπορούμε να ομαδοποιούμε τους προσθετέους για ευκολία.

Ιδιότητες

  1. Γενικευμένη Αντιμεταθετική: Το άθροισμα δεν αλλάζει αν αλλάξουμε τη σειρά των προσθετέων.

  2. Γενικευμένη Προσεταιριστική: Μπορούμε να αντικαταστήσουμε μερικούς προσθετέους με το άθροισμά τους χωρίς να αλλάξει το τελικό αποτέλεσμα.

  3. Στρατηγική Υπολογισμού: Συνήθως προσθέτουμε χωριστά όλους τους θετικούς και χωριστά όλους τους αρνητικούς, και στο τέλος προσθέτουμε τα δύο αποτελέσματα (ετερόσημοι).

Παραδείγματα

  1. \(4 + 3 + 2 + 5 = 14\).
  2. \((-3) + (+5) + (-2) + (+1) = [(-3) + (-2)] + [(+5) + (+1)] = (-5) + (+6) = +1\).
  3. \(\dfrac{1}{4} + \dfrac{1}{6} + \dfrac{1}{9} = \dfrac{9+6+4}{36} = \dfrac{19}{36}\).
  4. \(17 + (-13) + (-17) + 13 = [17 + (-17)] + [(-13) + 13] = 0 + 0 = 0\) (Ομαδοποίηση αντιθέτων).
  5. \((-10) + (+25) + (-5) = (-15) + (+25) = +10\).

1.3 Ιδιότητες της πρόσθεσης και η σημασία τους

Θεωρία και Σημασία

Οι ιδιότητες της πρόσθεσης επιτρέπουν την απλοποίηση σύνθετων παραστάσεων και τη διευκόλυνση του νοερού λογισμού (από μνήμης).

Βασικές Ιδιότητες

  1. Αντιμεταθετική: \(a + \beta = \beta + a\).
  2. Προσεταιριστική: \((a + \beta) + \gamma = a + (\beta + \gamma)\).
  3. Νόμος της Διαγραφής (Cancellation Law): Αν \(a + \gamma = \beta + \gamma\), τότε \(a = \beta\). Είναι κρίσιμος για την επίλυση εξισώσεων της μορφής \(x + a = \beta\).
  4. Ύπαρξη Αντιθέτου: Για κάθε ρητό \(a\), υπάρχει ο \(-a\) ώστε \(a + (-a) = 0\).

Σημασία στον υπολογισμό: Επιτρέπει την κατάργηση παρενθέσεων και τη χρήση στρατηγικών όπως το “συμπλήρωμα στον επόμενο ακέραιο” ή την ομαδοποίηση όρων που δίνουν “βολικά” αθροίσματα (π.χ. 10, 100, 0).

Παραδείγματα

  1. Ομαδοποίηση: \(17 + 29 + 43 + 61 = (17 + 43) + (29 + 61) = 60 + 90 = 150\).
  2. Διαγραφή: Στην εξίσωση \(x + 8 = 12 + 8\), διαγράφουμε το 8 και βρίσκουμε \(x = 12\).
  3. Κατάργηση παρενθέσεων: \(12 + (5 + 7) = 12 + 5 + 7 = 24\).
  4. Συμπλήρωμα: \(70 + 68 = 70 + (30 + 38) = 100 + 38 = 138\).
  5. Αντίθετοι: \((-4,5) + (+2,1) + (+4,5) = [(-4,5) + (+4,5)] + 2,1 = 0 + 2,1 = 2,1\).

Ασκήσεις

  1. Υπολογίστε νοερά με ομαδοποίηση: \(6 + 21 + 84 + 9\).
  2. Χρησιμοποιήστε τη διαγραφή για να λύσετε την \(x + 15 = 20 + 15\).
  3. Απλοποιήστε την παράσταση καταργώντας παρενθέσεις: \(a + (10 - \beta)\).
  4. Βρείτε το \(x\) αν \(x + 3 = 10\) χρησιμοποιώντας την αντίστροφη πράξη.
  5. Επαληθεύστε την αντιμεταθετική ιδιότητα για τους ρητούς \(1/2\) και \(3/4\).
  6. Υπολογίστε το \((34 + 23) + (77 + 56)\) με ομαδοποίηση.
  7. Στην ισότητα \(a + \beta = a\), ποια είναι η τιμή του \(\beta\);.
  8. Χρησιμοποιήστε τη διάσπαση όρου: \(57 + 9 = 56 + 10 = \dots\).
  9. Απλοποιήστε: \(2 \cdot (x + 2) + 3 \cdot (x - 1)\).
  10. Αν \(a = \beta\), είναι αληθές ότι \(a + 5 = \beta + 5\); Αιτιολογήστε.
  11. Υπολογίστε το \(13 + (3 + 5) + [8 + (7 + 6)]\).
  12. Βρείτε τον \(x\) στην \(x - 5 + 7 = 8 + (5 - 2)\).
  13. Χρησιμοποιήστε την επιμεριστική ιδιότητα: \(5 \cdot (a + \beta + \gamma)\).
  14. Αν \(a + \beta + \gamma = a + \beta\), τι συμπεραίνετε για το \(\gamma\);.
  15. Υπολογίστε το άθροισμα τριών διαδοχικών ακεραίων αν ο μεσαίος είναι \(x\).
