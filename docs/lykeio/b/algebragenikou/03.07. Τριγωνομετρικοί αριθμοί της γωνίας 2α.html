1 Τριγωνομετρικοί αριθμοί της γωνίας 2α

1.1 Τύποι Διπλάσιας Γωνίας (\(2α\)) και Αποδείξεις

Οι τύποι του διπλάσιου τόξου προκύπτουν άμεσα από τους τύπους αθροίσματος γωνιών:

  • \(ημ(α + β) = ημα συνβ + συνα ημβ\)

  • \(συν(α + β) = συνα συνβ - ημα ημβ\)

  • \(εφ(α + β) = \dfrac{εφα + εφβ}{1 - εφα εφβ}\)

  • \(σφ(α + β) = \dfrac{σφα σφβ - 1}{σφβ + σφα}\)

Θέτοντας όπου \(β = α\), λαμβάνουμε:

1.1.1 α) Ημίτονο Διπλάσιας Γωνίας:

\[\mathbf{ημ(2α) = 2ημα συνα}\]

  • Απόδειξη:

    \[ημ(2α) = ημ(α + α) = ημα συνα + συνα ημα = 2ημα συνα\]

1.1.2 β) Συνημίτονο Διπλάσιας Γωνίας:

\[\mathbf{συν(2α) = συν^2α - ημ^2α = 2συν^2α - 1 = 1 - 2ημ^2α}\]

  • Απόδειξη:

    1. \(συν(2α) = συν(α + α) = συνα συνα - ημα ημα = συν^2α - ημ^2α\).

    2. Αντικαθιστώντας \(ημ^2α = 1 - συν^2α\): \[συν(2α) = συν^2α - (1 - συν^2α) = 2συν^2α - 1\]

    3. Αντικαθιστώντας \(συν^2α = 1 - ημ^2α\): \[συν(2α) = (1 - ημ^2α) - ημ^2α = 1 - 2ημ^2α\]

1.1.3 γ) Εφαπτομένη Διπλάσιας Γωνίας:

\[\mathbf{εφ(2α) = \frac{2εφα}{1 - εφ^2α}} \quad \left(\text{με } συνα \neq 0, εφ^2α \neq 1, συν(2α) \neq 0\right)\]

  • Απόδειξη: \[εφ(2α) = εφ(α + α) = \frac{εφα + εφα}{1 - εφα \cdot εφα} = \frac{2εφα}{1 - εφ^2α}\]

1.1.4 δ) Συνεφαπτομένη Διπλάσιας Γωνίας:

\[\mathbf{σφ(2α) = \frac{σφ^2α - 1}{2σφα}} \quad \left(\text{με } ημα \neq 0, σφα \neq 0, ημ(2α) \neq 0\right)\]

  • Απόδειξη:

    \[σφ(2α) = σφ(α + α) = \frac{σφα \cdot σφα - 1}{σφα + σφα} = \frac{σφ^2α - 1}{2σφα}\]

1.2 Τύποι Αποτετραγωνισμού (Υποβιβασμού Εκθέτη)

Οι τύποι αποτετραγωνισμού εκφράζουν τις δυνάμεις \(ημ^2α\), \(συν^2α\) και \(εφ^2α\) ως προς τη γραμμική παράσταση του \(συν(2α)\):

\[\mathbf{ημ^2α = \frac{1 - συν(2α)}{2}}, \quad \mathbf{συν^2α = \frac{1 + συν(2α)}{2}}, \quad \mathbf{εφ^2α = \frac{1 - συν(2α)}{1 + συν(2α)}}\]

  • Αποδείξεις:

    1. Από τον τύπο \(συν(2α) = 1 - 2ημ^2α \iff 2ημ^2α = 1 - συν(2α) \iff \mathbf{ημ^2α = \dfrac{1 - συν(2α)}{2}}\).
