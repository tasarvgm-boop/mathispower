1 Πολυώνυμα

1.1 Μονώνυμο, Έννοια Πολυωνύμου & Ίσα Πολυώνυμα

α) Μονώνυμο του \(x\)

Ορισμός:

Καλούμε μονώνυμο του \(x\) κάθε παράσταση της μορφής \(\alpha x^\nu\), όπου \(\alpha\) είναι ένας πραγματικός αριθμός (συντελεστής) και \(\nu\) ένας μη αρνητικός ακέραιος (φυσικός αριθμός). Μονώνυμο του \(x\) καλούμε επίσης και κάθε πραγματικό αριθμό.

  • Παραδείγματα:

    • Οι παραστάσεις \(3x^2\), \(-\dfrac{1}{2}x^5\), \(x\), καθώς και οι αριθμοί \(7\), \(-4\), \(0\) είναι μονώνυμα του \(x\).

    • Παραστάσεις όπως \(2x^{-3}\), \(\dfrac{4}{x}\) ή \(3\sqrt{x}\) δεν είναι μονώνυμα του \(x\), διότι ο εκθέτης της μεταβλητής δεν είναι φυσικός αριθμός.

β) Έννοια του Πολυωνύμου

Ορισμός:

Καλούμε πολυώνυμο του \(x\) κάθε αλγεβρική παράσταση της μορφής: \[P(x) = \alpha_\nu x^\nu + \alpha_{\nu-1} x^{\nu-1} + \dots + \alpha_1 x + \alpha_0\] όπου \(\nu \in \mathbb{N}\) και \(\alpha_0, \alpha_1, \dots, \alpha_\nu \in \mathbb{R}\).

  • Βασικά Στοιχεία Πολυωνύμου:

    • Όροι: Τα μονώνυμα \(\alpha_\nu x^\nu, \alpha_{\nu-1} x^{\nu-1}, \dots, \alpha_1 x, \alpha_0\).

    • Συντελεστές: Οι πραγματικοί αριθμοί \(\alpha_\nu, \alpha_{\nu-1}, \dots, \alpha_1, \alpha_0\).

    • Σταθερός όρος: Ο συντελεστής \(\alpha_0\) (ο όρος μηδενικού βαθμού).

    • Σταθερό πολυώνυμο: Κάθε πολυώνυμο της μορφής \(P(x) = \alpha_0\) (δηλαδή ένας πραγματικός αριθμός). Αν \(\alpha_0 \neq 0\), έχει βαθμό \(0\).

    • Μηδενικό πολυώνυμο: Το σταθερό πολυώνυμο \(0\) (όλοι οι συντελεστές του είναι μηδέν). Για το μηδενικό πολυώνυμο δεν ορίζεται βαθμός.

    • Βαθμός πολυωνύμου: Αν το \(P(x)\) δεν είναι μηδενικό, βαθμός του είναι ο μεγαλύτερος εκθέτης \(\kappa\) της μεταβλητής \(x\) για τον οποίο ο αντίστοιχος συντελεστής \(\alpha_\kappa\) είναι διαφορετικός από το μηδέν (\(\alpha_\kappa \neq 0\)). Συμβολίζεται με \(\text{deg}(P(x))\).

  • Παραδείγματα:

    • Το \(P(x) = 4x^3 - 2x^2 + 7x - 5\) είναι πολυώνυμο 3ου βαθμού με συντελεστές \(4, -2, 7, -5\) και σταθερό όρο \(-5\).

    • Το \(Q(x) = 8\) είναι σταθερό πολυώνυμο βαθμού \(0\).

    • Το \(R(x) = 0x^2 + 0x + 0\) είναι το μηδενικό πολυώνυμο (χωρίς βαθμό).

    • Τα \(\dfrac{4}{y}-5y^2-2\), \(\ \ 2\sqrt{a}+8\), \(\ \ x^{-2}+5x-x^3\), \(\ \ \ 6-2t+t^{\dfrac{3}{2}}\) δεν είναι πολυώνυμα.

γ) Ίσα Πολυώνυμα

Ορισμός:

Δύο πολυώνυμα \(P(x) = \alpha_\mu x^\mu + \dots + \alpha_1 x + \alpha_0\) και \(Q(x) = \beta_\nu x^\nu + \dots + \beta_1 x + \beta_0\) (με \(\mu \ge \nu\)) λέγονται ίσα όταν οι συντελεστές των αντίστοιχων ομοβάθμιων όρων τους είναι ίσοι: \[\alpha_0 = \beta_0, \quad \alpha_1 = \beta_1, \quad \dots, \quad \alpha_\nu = \beta_\nu \quad \text{και} \quad \alpha_{\nu+1} = \dots = \alpha_\mu = 0\]

  • Παράδειγμα: Τα πολυώνυμα \(P(x) = (\lambda - 1)x^2 + 3x + \mu\) και \(Q(x) = 2x^2 + (\kappa + 1)x - 4\) είναι ίσα αν και μόνο αν εξισώσουμε τους αντίστοιχους συντελεστές: \[\lambda - 1 = 2 \implies \mathbf{\lambda = 3}\] \[\kappa + 1 = 3 \implies \mathbf{\kappa = 2}\] \[\mathbf{\mu = -4}\]

1.2 Αριθμητική Τιμή & Ρίζα Πολυωνύμου

α) Αριθμητική Τιμή Πολυωνύμου

Ορισμός:

Έστω ένα πολυώνυμο \(P(x) = \alpha_\nu x^\nu + \alpha_{\nu-1} x^{\nu-1} + \dots + \alpha_1 x + \alpha_0\). Αν αντικαταστήσουμε το \(x\) με έναν ορισμένο πραγματικό αριθμό \(\rho\), ο πραγματικός αριθμός: \[P(\rho) = \alpha_\nu \rho^\nu + \alpha_{\nu-1} \rho^{\nu-1} + \dots + \alpha_1 \rho + \alpha_0\] που προκύπτει ονομάζεται αριθμητική τιμή (ή απλά τιμή) του πολυωνύμου για \(x = \rho\).

  • Χαρακτηριστικά:

    • Η τιμή του σταθερού πολυώνυμου \(c\) ισούται με \(c\) για όλες τις τιμές του \(x\).

    • Τα ίσα πολυώνυμα έχουν ίσες τιμές για όλες τις τιμές του \(x\).

    • Για \(x = 0\), η τιμή \(P(0)\) ισούται πάντοτε με τον σταθερό όρο \(\alpha_0\) του πολυωνύμου.

  • Παράδειγμα: Για το πολυώνυμο \(P(x) = 2x^3 - 4x^2 + x + 5\):

    • Για \(x = 2\): \(P(2) = 2(2)^3 - 4(2)^2 + 2 + 5 = 16 - 16 + 2 + 5 = \mathbf{7}\).

    • Για \(x = 0\): \(P(0) = \mathbf{5}\).

β) Ρίζα Πολυωνύμου

Ορισμός:

Ένας πραγματικός αριθμός \(\rho\) ονομάζεται ρίζα του πολυωνύμου \(P(x)\) αν η αριθμητική τιμή του πολυωνύμου για \(x = \rho\) είναι μηδέν, δηλαδή αν: \[\mathbf{P(\rho) = 0}\]

  • Παράδειγμα: Για το πολυώνυμο \(P(x) = x^3 - 2x^2 - x + 2\):

    • Για \(x = 1\): \(P(1) = 1^3 - 2(1)^2 - 1 + 2 = 1 - 2 - 1 + 2 = 0\). Άρα ο αριθμός \(1\) είναι ρίζα του \(P(x)\).

    • Για \(x = 2\): \(P(2) = 2^3 - 2(2)^2 - 2 + 2 = 8 - 8 - 2 + 2 = 0\). Άρα και ο αριθμός \(2\) είναι ρίζα του \(P(x)\).

    • Για \(x = 0\): \(P(0) = 2 \neq 0\). Άρα το \(0\) δεν είναι ρίζα του \(P(x)\).

1.3 Πράξεις με Πολυώνυμα

Μπορούμε να προσθέσουμε, να αφαιρέσουμε ή να πολλαπλασιάσουμε πολυώνυμα εφαρμόζοντας τις ιδιότητες των πραγματικών αριθμών:

α) Πρόσθεση & Αφαίρεση Πολυωνύμων

  • Διαδικασία: Προσθέτουμε ή αφαιρούμε τους συντελεστές των ομοίων όρων (αναγωγή ομοίων όρων).

  • Βαθμός Αθροίσματος / Διαφοράς: Αν το άθροισμα δύο μη μηδενικών πολυωνύμων \(P(x)\) και \(Q(x)\) είναι μη μηδενικό πολυώνυμο, τότε ο βαθμός του είναι ίσος ή μικρότερος από το μέγιστο των βαθμών των δύο πολυωνύμων: \[\text{deg}(P(x) + Q(x)) \le \max(\text{deg}(P(x)), \text{deg}(Q(x)))\]

  • Παράδειγμα: Δίνονται \(P(x) = 3x^3 - 2x^2 + 5x - 1\) και \(Q(x) = -3x^3 + 4x^2 - 2x + 6\).

    • Άθροισμα: \[P(x) + Q(x) = (3x^3 - 3x^3) + (-2x^2 + 4x^2) + (5x - 2x) + (-1 + 6) =\\ \mathbf{2x^2 + 3x + 5}\]

      (Παρατηρούμε ότι ο βαθμός μειώθηκε από 3 σε 2 διότι οι μεγιστοβάθμιοι όροι αλληλοαναιρέθηκαν).

    • Διαφορά: \[P(x) - Q(x) = (3x^3 - 2x^2 + 5x - 1) - (-3x^3 + 4x^2 - 2x + 6)\] \[= 3x^3 - 2x^2 + 5x - 1 + 3x^3 - 4x^2 + 2x - 6 = \mathbf{6x^3 - 6x^2 + 7x - 7}\]

β) Πολλαπλασιασμός Πολυωνύμων

  • Διαδικασία: Πολλαπλασιάζουμε κάθε όρο του πρώτου πολυωνύμου με κάθε όρο του δεύτερου πολυωνύμου (επιμεριστική ιδιότητα) και στη συνέχεια κάνουμε αναγωγή ομοίων όρων.

  • Βαθμός Γινομένου: Ο βαθμός του γινομένου δύο μη μηδενικών πολυωνύμων \(P(x)\) και \(Q(x)\) είναι ίσος με το άθροισμα των βαθμών των δύο πολυωνύμων: \[\text{deg}(P(x) \cdot Q(x)) = \text{deg}(P(x)) + \text{deg}(Q(x))\]

  • Παράδειγμα: Δίνονται \(P(x) = 2x^2 - 3x + 1\) (2ου βαθμού) και \(Q(x) = x - 2\) (1ου βαθμού). \[P(x) \cdot Q(x) = (2x^2 - 3x + 1)(x - 2) = 2x^2(x - 2) - 3x(x - 2) + 1(x - 2)\] \[= 2x^3 - 4x^2 - 3x^2 + 6x + x - 2 = \mathbf{2x^3 - 7x^2 + 7x - 2}\]

    (Ο βαθμός του γινομένου είναι \(2 + 1 = 3\)).

1.4 Εφαρμογές

Εφαρμογή 1: Μηδενικό Πολυώνυμο

Εκφώνηση:

Να βρεθούν οι τιμές του \(\alpha \in \mathbb{R}\) για τις οποίες το πολυώνυμο
\[P(x) = (\alpha^2 - 4)x^3 + (\alpha^2 - \alpha - 2)x + (\alpha - 2)\]
είναι το μηδενικό πολυώνυμο (\(P(x) = 0\)).

Λύση

Θεωρία

Ένα πολυώνυμο είναι το μηδενικό πολυώνυμο αν και μόνο αν όλοι οι συντελεστές των όρων του καθώς και ο σταθερός όρος είναι ίσοι με το \(0\) ταυτόχρονα.

Πρέπει να συναληθεύουν οι εξισώσεις:

\[\begin{cases} \alpha^2 - 4 = 0 & (1) \\ \alpha^2 - \alpha - 2 = 0 & (2) \\ \alpha - 2 = 0 & (3) \end{cases}\]

  1. Λύση της εξίσωσης (1): \[\alpha^2 - 4 = 0 \iff \alpha^2 = 4 \iff \alpha = 2 \quad \text{ή} \quad \alpha = -2\]

  2. Λύση της εξίσωσης (2):

    Είναι δευτεροβάθμια εξίσωση με διακρίνουσα: \[\Delta = (-1)^2 - 4 \cdot 1 \cdot (-2) = 1 + 8 = 9\] Άρα οι ρίζες είναι: \[\alpha = \frac{-(-1) \pm \sqrt{9}}{2 \cdot 1} = \frac{1 \pm 3}{2}\] Οπότε: \[\alpha = \frac{1 + 3}{2} = 2 \quad \text{ή} \quad \alpha = \frac{1 - 3}{2} = -1\]

  3. Λύση της εξίσωσης (3): \[\alpha - 2 = 0 \iff \alpha = 2\]

  4. Συναλήθευση:

    Η μοναδική τιμή του \(\alpha\) που ικανοποιεί και τις τρεις εξισώσεις ταυτόχρονα είναι: \[\alpha = 2\]

Εφαρμογή 2: Ισότητα Πολυωνύμων

Εκφώνηση:

Να βρεθούν οι τιμές του \(\mu \in \mathbb{R}\) για τις οποίες τα πολυώνυμα
\[A(x) = \mu^2 x^3 + (\mu - 3)x^2 + 5\]
και
\[B(x) = (7\mu - 12)x^3 + (\mu^2 - 9)x^2 + \mu + 2\]
είναι ίσα.

Λύση

Θεωρία

Δύο πολυώνυμα είναι ίσα αν και μόνο αν οι συντελεστές των ομοβάθμιων όρων τους είναι ίσοι, καθώς και οι σταθεροί όροι τους.

Για να ισχύει \(A(x) = B(x)\), πρέπει να ισχύουν ταυτόχρονα: \[\begin{cases} \mu^2 = 7\mu - 12 & (\text{συντελεστές του } x^3) \\ \mu - 3 = \mu^2 - 9 & (\text{συντελεστές του } x^2) \\ 5 = \mu + 2 & (\text{σταθεροί όροι}) \end{cases}\]

  1. Λύση της 3ης εξίσωσης (σταθεροί όροι): \[5 = \mu + 2 \iff \mu = 5 - 2 \iff \mu = 3\]

  2. Έλεγχος της τιμής \(\mu = 3\) στις υπόλοιπες δύο εξισώσεις:

    • Για την 1η εξίσωση (\(\mu^2 = 7\mu - 12\)): \[\mu^2 - 7\mu + 12 = 0\]

      Για \(\mu = 3\): \[3^2 - 7 \cdot 3 + 12 = 9 - 21 + 12 = 0 \quad (\text{ισχύει})\]

    • Για τη 2η εξίσωση (\(\mu - 3 = \mu^2 - 9\)): \[\mu^2 - \mu - 6 = 0\]

      Για \(\mu = 3\): \[3^2 - 3 - 6 = 9 - 3 - 6 = 0 \quad (\text{ισχύει})\]

  3. Συμπέρασμα:
    Η τιμή του \(\mu\) για την οποία τα πολυώνυμα είναι ίσα είναι: \[\mu = 3\]

Εφαρμογή 3: Ισότητα Πολυωνύμων

Εκφώνηση:

Αν \(P(x) = x^2 + 5x + \alpha^2 - 4\), να βρεθούν οι τιμές του \(\alpha \in \mathbb{R}\) για τις οποίες ισχύει \(P(-2) = 2\).

Λύση

  1. Υπολογισμός της αριθμητικής τιμής \(P(-2)\):

    Αντικαθιστούμε όπου \(x\) το \(-2\) στον τύπο του πολυωνύμου: \[P(-2) = (-2)^2 + 5(-2) + \alpha^2 - 4\] \[P(-2) = 4 - 10 + \alpha^2 - 4\] \[P(-2) = \alpha^2 - 10\]

  2. Εξίσωση με τη δοσμένη τιμή:

    Θέτουμε \(P(-2) = 2\): \[\alpha^2 - 10 = 2\] \[\alpha^2 = 2 + 10\] \[\alpha^2 = 12\]

  3. Επίλυση ως προς \(\alpha\):
    \[\alpha = \pm\sqrt{12} \iff \alpha = \pm 2\sqrt{3}\]

Άρα, οι ζητούμενες τιμές είναι: \[\alpha = 2\sqrt{3} \quad \text{ή} \quad \alpha = -2\sqrt{3}\]

Εφαρμογή 4: Ισότητα Πολυωνύμων

Εκφώνηση:

Αν \(P(x) = 2x^2 - 4x + 3\alpha^2 - 5\alpha\), να βρεθούν οι τιμές του \(\alpha \in \mathbb{R}\) για τις οποίες ισχύει \(P(1) = 4\).

Λύση

  1. Υπολογισμός της αριθμητικής τιμής \(P(1)\):

    Αντικαθιστούμε όπου \(x\) το \(1\): \[P(1) = 2(1)^2 - 4(1) + 3\alpha^2 - 5\alpha\] \[P(1) = 2(1) - 4 + 3\alpha^2 - 5\alpha\] \[P(1) = 2 - 4 + 3\alpha^2 - 5\alpha\] \[P(1) = 3\alpha^2 - 5\alpha - 2\]

  2. Εξίσωση με τη δοσμένη τιμή:

    Θέτουμε \(P(1) = 4\): \[3\alpha^2 - 5\alpha - 2 = 4\] \[3\alpha^2 - 5\alpha - 6 = 0\]

  3. Επίλυση της δευτεροβάθμιας εξίσωσης:

    Υπολογίζουμε τη διακρίνουσα (\(\Delta\)): \[\Delta = \beta^2 - 4\alpha\gamma = (-5)^2 - 4 \cdot 3 \cdot (-6) = 25 + 72 = 97\]

    Επειδή \(\Delta > 0\), υπάρχουν δύο πραγματικές λύσεις: \[\alpha = \frac{-\beta \pm \sqrt{\Delta}}{2\alpha} = \frac{-(-5) \pm \sqrt{97}}{2 \cdot 3} = \frac{5 \pm \sqrt{97}}{6}\]

Άρα, οι ζητούμενες τιμές είναι: \[\alpha = \frac{5 + \sqrt{97}}{6} \quad \text{ή} \quad \alpha = \frac{5 - \sqrt{97}}{6}\]

Η εργασία των μαθηματικών του Πέτρου φαίνεται παρακάτω. Βρείτε και διορθώστε τα λάθη του.

Εργασία:

Δίνεται η παράσταση \(p(x) = x + \frac{4}{x} - 5\). Απαντήστε στις παρακάτω ερωτήσεις:

  • α) Απλοποιήστε την παράσταση.

  • β) Είναι η \(p(x)\) πολυώνυμο;

  • γ) Ποιος είναι ο συντελεστής του όρου \(x\);

Οι απαντήσεις του Πέτρου και τα λάθη του

Ερώτημα (α):

  • Τι έγραψε ο Πέτρος: \[p(x) = x + \frac{4}{x} - 5\] \[= x^2 + 4 - 5x \quad (\pi\mathrm{o\lambda\lambda\alpha\pi\lambda\alpha\sigma\iota\alpha\sigma\mu\text{ό}\varsigma \; \mu\epsilon} \; x)\] \[= x^2 - 5x + 4\] \[= (x - 1)(x + 4)\]

  • Εντοπισμός λαθών:

    1. Αυθαίρετος πολλαπλασιασμός με \(x\): Ο Πέτρος πολλαπλασίασε την παράσταση με \(x\), αλλάζοντας την τιμή της. Επιτρέπεται να πολλαπλασιάσουμε με \(x\) μόνο αν πρόκειται για εξίσωση (και στα δύο μέλη), όχι όμως σε μία αλγεβρική παράσταση. Για να απλοποιηθεί μία τέτοια παράσταση, κάνουμε τα κλάσματα ομώνυμα (κοινός παρονομαστής το \(x\)).

    2. Λάθος παραγοντοποίηση: Ακόμη και για το τριώνυμο \(x^2 - 5x + 4\), η παραγοντοποίηση δεν είναι \((x - 1)(x + 4)\), καθώς \((x - 1)(x + 4) = x^2 + 3x - 4\). Το σωστό είναι \((x - 1)(x - 4)\).

  • Σωστή λύση για το (α):

    Περιορισμός: \(x \neq 0\).

    Κάνουμε ομώνυμα με κοινό παρονομαστή το \(x\): \[p(x) = \frac{x \cdot x}{x} + \frac{4}{x} - \frac{5x}{x} = \frac{x^2 - 5x + 4}{x}\]

    Παραγοντοποιώντας τον αριθμητή: \[p(x) = \frac{(x - 1)(x - 4)}{x}\]

Ερώτημα (β):

  • Τι έγραψε ο Πέτρος:
    «Ναι, επειδή μπορεί να απλοποιηθεί ώστε όλοι οι εκθέτες να είναι φυσικοί αριθμοί. Είναι δευτεροβάθμιο διώνυμο επειδή ο μεγαλύτερος εκθέτης είναι δύο και υπάρχουν μόνο δύο όροι: \((x - 1)\) και \((x + 4)\).»

  • Εντοπισμός λαθών:

    1. Η παράσταση δεν είναι πολυώνυμο. Ο όρος \(\dfrac{4}{x}\) γράφεται ως \(4x^{-1}\). Ο εκθέτης του \(x\) είναι \(-1\), ο οποίος δεν είναι μη αρνητικός ακέραιος (φυσικός αριθμός).

    2. Οι παράγοντες \((x - 1)\) και \((x + 4)\) σε ένα γινόμενο δεν ονομάζονται «όροι» αλλά «παράγοντες». Άρα δεν πρόκειται για διώνυμο.

  • Σωστή απάντηση για το (β):

    Όχι, η \(p(x)\) δεν είναι πολυώνυμο.

    Αιτιολόγηση: Στην αρχική παράσταση εμφανίζεται ο όρος \(\dfrac{4}{x} = 4x^{-1}\). Για να είναι μια παράσταση πολυώνυμο, όλοι οι εκθέτες της μεταβλητής \(x\) πρέπει να είναι μη αρνητικοί ακέραιοι (\(\{0, 1, 2, \dots\}\)). Εδώ ο εκθέτης είναι \(-1 \notin \mathbb{N}\).

Ερώτημα (γ):

  • Τι έγραψε ο Πέτρος:
    «Πριν απλοποιήσω, ο συντελεστής του όρου \(x\) ήταν τίποτα και μετά την απλοποίηση έγινε \(5\).»

  • Εντοπισμός λαθών:

    1. Στην αρχική έκφραση για το συντελεστή του \(x\), ο συντελεστής δεν είναι «τίποτα» (ή \(0\)), αλλά \(1\), καθώς \(x = 1 \cdot x\).

    2. Στην τροποποιημένη του έκφραση \(x^2 - 5x + 4\), ο συντελεστής του \(x\) είναι \(-5\) και όχι \(5\) (ξέχασε το πρόσημο μείον).

  • Σωστή απάντηση για το (γ):

    Ο συντελεστής του όρου \(x\) στην αρχική παράσταση \(p(x) = x + \dfrac{4}{x} - 5\) είναι το \(1\) (αφού \(x = 1x^1\)).

    Αντικαθιστώντας \(\alpha = 2\) και \(\beta = -4\) στο \(P(x)\): \[P(x) = x^3 - 2x^2 + (-4 - 1)x + 6 \iff \mathbf{P(x) = x^3 - 2x^2 - 5x + 6}\]

  • Β2.2:

    Υπολογίζουμε την αριθμητική τιμή για \(x = -1\): \[P(-1) = (-1)^3 - 2(-1)^2 - 5(-1) + 6 = -1 - 2(1) + 5 + 6 = -3 + 11 = \mathbf{8}\]

  • Β3:

    Υπολογίζουμε το \(P(3)\): \[P(3) = 3^3 - 2(3)^2 - 5(3) + 6 = 27 - 2(9) - 15 + 6 = 27 - 18 - 15 + 6 = 0\]

    Επειδή \(P(3) = 0\), ο αριθμός \(x = 3\) είναι πράγματι ρίζα του πολυωνύμου \(P(x)\).

3.3 ΘΕΜΑ Γ

  • Γ1.1:

    Για να είναι το \(P(x)\) το μηδενικό πολυώνυμο, πρέπει όλοι οι συντελεστές του να ισούνται με το μηδέν:

    • \(\lambda^2 - 1 = 0 \iff \lambda = 1 \text{ ή } \lambda = -1\)

    • \(\mu + 2 = 0 \iff \mu = -2\)

    • \(\kappa - 5 = 0 \iff \kappa = 5\)

    • \(\nu - 3 = 0 \iff \nu = 3\)

  • Γ1.2:

    Για να είναι \(P(x) = Q(x)\), εξισώνουμε τους συντελεστές των ομοβάθμιων όρων:

    • Ο συντελεστής του \(x^3\) στο \(Q(x)\) είναι \(0\), άρα: \(\lambda^2 - 1 = 0 \iff \mathbf{\lambda = 1 \text{ ή } \lambda = -1}\)

    • Συντελεστής του \(x^2\): \(\mu + 2 = 3 \iff \mathbf{\mu = 1}\)

    • Συντελεστής του \(x\): \(\kappa - 5 = -1 \iff \mathbf{\kappa = 4}\)

    • Σταθερός όρος: \(\nu - 3 = 2 \iff \mathbf{\nu = 5}\)

  • Γ2.1:
    \[A(x) = f(x) + g(x) = (2x^2 - 3x + 1) + (x - 2) = \mathbf{2x^2 - 2x - 1}\]

    Ο βαθμός του \(A(x)\) είναι \(2\).

  • Γ2.2:
    \[B(x) = f(x) \cdot g(x) = (2x^2 - 3x + 1)(x - 2) = 2x^2(x - 2) - 3x(x - 2) + 1(x - 2)\] \[= 2x^3 - 4x^2 - 3x^2 + 6x + x - 2 = \mathbf{2x^3 - 7x^2 + 7x - 2}\]

    Ο βαθμός του \(B(x)\) είναι \(3\) (\(\text{deg}(f) + \text{deg}(g) = 2 + 1 = 3\)).

  • Γ2.3:

    Υπολογίζουμε τις αριθμητικές τιμές για \(x = 1\):

    • \(f(1) = 2(1)^2 - 3(1) + 1 = 2 - 3 + 1 = 0 \implies \text{το } x = 1 \text{ είναι ρίζα του } f(x)\).

    • \(B(1) = f(1) \cdot g(1) = 0 \cdot (1 - 2) = 0 \implies \text{το } x = 1 \text{ είναι ρίζα του } B(x)\).

    Άρα το \(x = 1\) είναι κοινή ρίζα των \(f(x)\) και \(B(x)\).

3.4 ΘΕΜΑ Δ

  • Δ1.1:

    Ο μεγιστοβάθμιος συντελεστής είναι ο \(\alpha - 2\):

    • Αν \(\alpha \neq 2\), τότε \(\alpha - 2 \neq 0\), οπότε το πολυώνυμο είναι \(3\)ου βαθμού.

    • Αν \(\alpha = 2\), ο όρος \(x^3\) μηδενίζεται. Επίσης, \(\alpha^2 - 4 = 2^2 - 4 = 0\), οπότε ο όρος \(x^2\) επίσης μηδενίζεται.

      Το πολυώνυμο γίνεται \(P(x) = (2 + 1)x + \beta - 5 = 3x + \beta - 5\).

      Επειδή ο συντελεστής του \(x\) είναι \(3 \neq 0\), το \(P(x)\) είναι \(1\)ου βαθμού.

  • Δ1.2:

    Για να είναι το \(P(x)\) \(1\)ου βαθμού, πρέπει \(\alpha = 2\) (από το Δ1.1).

    Για να είναι ο σταθερός όρος του ίσος με \(0\), πρέπει: \[P(0) = 0 \iff \beta - 5 = 0 \iff \mathbf{\beta = 5}\]

  • Δ2.1:

    Λύνουμε την εξίσωση \(Q(x) = 0\): \[x^2 - 4x + 3 = 0 \iff (x - 1)(x - 3) = 0 \iff \mathbf{x = 1 \text{ ή } x = 3}\]

    Άρα οι ρίζες του \(Q(x)\) είναι οι αριθμοί \(1\) και \(3\).

  • Δ2.2:

    Υπολογίζουμε τις τιμές \(Q(0)\) και \(Q(4)\):

    • \(Q(0) = 0^2 - 4(0) + 3 = 3\)

    • \(Q(4) = 4^2 - 4(4) + 3 = 16 - 16 + 3 = 3\)

    Τώρα υπολογίζουμε τις τιμές του \(R(x) = Q(Q(x))\) για \(x = 0\) και \(x = 4\):

    • \(R(0) = Q(Q(0)) = Q(3) = 0\) (αφού το \(3\) είναι ρίζα του \(Q(x)\)).

    • \(R(4) = Q(Q(4)) = Q(3) = 0\) (αφού το \(3\) είναι ρίζα του \(Q(x)\)).

    Επειδή \(R(0) = 0\) και \(R(4) = 0\), οι αριθμοί \(x = 0\) και \(x = 4\) είναι πράγματι ρίζες του \(R(x)\).
