1 Μετασχηματισμοί τριγωνομετρικών παραστάσεων

1.1 Μετασχηματισμός Γινομένου σε Άθροισμα

Τύποι

Για οποιεσδήποτε γωνίες \(α, β \in \mathbb{R}\) ισχύουν οι παρακάτω θεμελιώδεις ταυτότητες:

  1. \(\mathbf{2ημα συνβ = ημ(α + β) + ημ(α - β)}\)

  2. \(\mathbf{2συνα συνβ = συν(α - β) + συν(α + β)}\)

  3. \(\mathbf{2ημα ημβ = συν(α - β) - συν(α + β)}\)

Απόδειξη

Από τους τύπους αθροίσματος και διαφοράς γωνιών γνωρίζουμε ότι:

\[ημ(α + β) = ημα συνβ + συνα ημβ \quad (1)\]

\[ημ(α - β) = ημα συνβ - συνα ημβ \quad (2)\]

\[συν(α + β) = συνα συνβ - ημα ημβ \quad (3)\]

\[συν(α - β) = συνα συνβ + ημα ημβ \quad (4)\]

  1. Προσθέτοντας κατά μέλη τις \((1)\) και \((2)\): \[ημ(α + β) + ημ(α - β) = 2ημα συνβ\]

  2. Προσθέτοντας κατά μέλη τις \((3)\) και \((4)\): \[συν(α - β) + συν(α + β) = 2συνα συνβ\]

  3. Αφαιρώντας κατά μέλη την \((3)\) από την \((4)\): \[συν(α - β) - συν(α + β) = 2ημα ημβ\]

1.1.1 Παραδείγματα

Παράδειγμα 1:

Να μετατραπεί σε άθροισμα το γινόμενο \(2ημ(5x)συν(3x)\).

Λύση

\(2ημ(5x)συν(3x) = ημ(5x + 3x) + ημ(5x - 3x) = \mathbf{ημ(8x) + ημ(2x)}\)$

Παράδειγμα 2:

Να υπολογιστεί η ακριβής τιμή του γινομένου \(A = συν 75^\circ \cdot συν 15^\circ\).

Λύση

\[συν 75^\circ \cdot συν 15^\circ = \frac{1}{2} \left[ συν(75^\circ - 15^\circ) + συν(75^\circ + 15^\circ) \right]\]

\[= \frac{1}{2} \left( συν 60^\circ + συν 90^\circ \right) = \frac{1}{2} \left( \frac{1}{2} + 0 \right) = \mathbf{\frac{1}{4}}\]

1.2 Μετασχηματισμός Αθροίσματος σε Γινόμενο

Τύποι

Για οποιεσδήποτε γωνίες \(A, B \in \mathbb{R}\) ισχύουν οι τύποι:

  1. \(ημ A + ημ B = 2ημ\left(\dfrac{A+B}{2}\right)συν\left(\dfrac{A-B}{2}\right)\)

  2. \(ημ A - ημ B = 2ημ\left(\dfrac{A-B}{2}\right)συν\left(\dfrac{A+B}{2}\right)\)

  3. \(συν A + συν B = 2συν\left(\dfrac{A+B}{2}\right)συν\left(\dfrac{A-B}{2}\right)\)

  4. \(συν A - συν B = -2ημ\left(\dfrac{A+B}{2}\right)ημ\left(\dfrac{A-B}{2}\right) = 2ημ\left(\dfrac{A+B}{2}\right)ημ\left(\dfrac{B-A}{2}\right)\)

Απόδειξη

Θέτουμε \(A = α + β\) και \(B = α - β\).

Προσθέτοντας και αφαιρώντας τις δύο εξισώσεις κατά μέλη προκύπτει: \[α = \frac{A + B}{2} \quad \text{και} \quad β = \frac{A - B}{2}\]

Αντικαθιστώντας τα \(α\) και \(β\) στους προηγούμενους τύπους μετασχηματισμού γινομένων σε αθροίσματα, λαμβάνουμε:

1.3 Εφαρμογές (Εξισώσεις & Ταυτότητες)

Εφαρμογή 1 (Εξίσωση με Μετασχηματισμό Γινομένων)

Να λυθεί στο \(\mathbb{R}\) η εξίσωση: \[ημ(3x)συν x = ημ(4x)συν(2x)\]

Λύση:

Πολλαπλασιάζουμε και τα δύο μέλη με \(2\):

\[2ημ(3x)συν x = 2ημ(4x)συν(2x)\]

Εφαρμόζουμε τους τύπους μετατροπής γινομένου σε άθροισμα:

\[ημ(3x+x) + ημ(3x-x) = ημ(4x+2x) + ημ(4x-2x)\] \[ημ(4x) + ημ(2x) = ημ(6x) + ημ(2x)\] \[ημ(6x) - ημ(4x) = 0\]

Μετατρέπουμε τη διαφορά ημιτόνων σε γινόμενο: \[2ημ\left(\frac{6x-4x}{2}\right)συν\left(\frac{6x+4x}{2}\right) = 0 \iff 2ημ x συν(5x) = 0\]

  • Από \(ημ x = 0 \iff \mathbf{x = k\pi}, \quad k \in \mathbb{Z}\)

  • Από \(συν(5x) = 0 \iff 5x = k\pi + \dfrac{\pi}{2} \iff \mathbf{x = \dfrac{k\pi}{5} + \dfrac{\pi}{10}}, \quad k \in \mathbb{Z}\)

Εφαρμογή 2 (Εξίσωση με Μετασχηματισμό Αθροίσματος)

Να λυθεί στο \(\mathbb{R}\) η εξίσωση: \[ημ(5x) + ημ(3x) + ημ x = 0\]

Λύση:

Ομαδοποιούμε τον πρώτο και τον τρίτο όρο: \[(ημ(5x) + ημ x) + ημ(3x) = 0\]

Μετατρέπουμε το άθροισμα \(ημ(5x) + ημ x\) σε γινόμενο: \[2ημ\left(\frac{5x+x}{2}\right)συν\left(\frac{5x-x}{2}\right) + ημ(3x) = 0\] \[2ημ(3x)συν(2x) + ημ(3x) = 0\]

Βγάζουμε κοινό παράγοντα το \(ημ(3x)\): \[ημ(3x)\left(2συν(2x) + 1\right) = 0\]

  • Από \(ημ(3x) = 0 \iff 3x = k\pi \iff \mathbf{x = \dfrac{k\pi}{3}}, \quad k \in \mathbb{Z}\)

  • Από \(2συν(2x) + 1 = 0 \iff συν(2x) = -\dfrac{1}{2} = συν\left(\dfrac{2\pi}{3}\right) \iff 2x = 2k\pi \pm \dfrac{2\pi}{3} \iff \mathbf{x = k\pi \pm \dfrac{\pi}{3}}, \quad k \in \mathbb{Z}\)

Να αποδειχθεί η ταυτότητα: \[\frac{ημ(3x) + ημ x}{συν(3x) + συν x} = εφ(2x) \quad \left(\text{για } συν(3x) + συν x \neq 0\right)\]

Λύση:

Μετατρέπουμε τον αριθμητή και τον παρονομαστή σε γινόμενα:

\[\text{Αριθμητής: } ημ(3x) + ημ x = 2ημ\left(\frac{3x+x}{2}\right)συν\left(\frac{3x-x}{2}\right) = 2ημ(2x)συν x\] \[\text{Παρονομαστής: } συν(3x) + συν x = 2συν\left(\frac{3x+x}{2}\right)συν\left(\frac{3x-x}{2}\right) = 2συν(2x)συν x\]

Συνθέτουμε το κλάσμα: \[\frac{2ημ(2x)συν x}{2συν(2x)συν x} = \frac{ημ(2x)}{συν(2x)} = \mathbf{εφ(2x)}\]

Εφαρμογή 4 (Ταυτότητα Γινομένων)

Να αποδειχθεί ότι: \[συν(2x)συν x - ημ(4x)ημ x = συν(3x)συν(2x)\]

Λύση:

Μετατρέπουμε τα δύο γινόμενα του αριστερού μέλους σε αθροίσματα:

  • \(συν(2x)συν x = \dfrac{1}{2}\left[συν(2x-x) + συν(2x+x)\right] = \dfrac{1}{2}\left(συν x + συν(3x)\right)\)

Αφαιρούμε τις δύο εκφράσεις: \[\text{Αριστερό Μέλος} = \frac{1}{2}\left(συν x + συν(3x)\right) - \frac{1}{2}\left(συν(3x) - συν(5x)\right)\] \[= \frac{1}{2}\left(συν x + συν(5x)\right)\]

Μετατρέπουμε το άθροισμα \(συν(5x) + συν x\) σε γινόμενο: \[= \frac{1}{2} \cdot 2συν\left(\frac{5x+x}{2}\right)συν\left(\frac{5x-x}{2}\right) = \mathbf{συν(3x)συν(2x)}\]

Για να αποδείξουμε την ταυτότητα, θα μετατρέψουμε το άθροισμα των δύο πρώτων όρων σε γινόμενο και θα χρησιμοποιήσουμε τη συνθήκη \(α + β + γ = \dfrac{\pi}{2}\).

1: Μετατροπή των δύο πρώτων όρων σε γινόμενο

Ξεκινάμε από το αριστερό μέλος (Α.Μ.): \[\text{A.M.} = ημ(2α) + ημ(2β) + ημ(2γ)\]

Χρησιμοποιούμε τον τύπο μετατροπής αθροίσματος ημιτόνων σε γινόμενο: \[ημ A + ημ B = 2ημ\left(\frac{A + B}{2}\right)συν\left(\frac{A - B}{2}\right)\]

Για \(A = 2α\) και \(B = 2β\), έχουμε: \[ημ(2α) + ημ(2β) = 2ημ\left(\frac{2α + 2β}{2}\right)συν\left(\frac{2α - 2β}{2}\right) = 2ημ(α + β)συν(α - β)\]

Επομένως, το αριστερό μέλος γίνεται: \[\text{A.M.} = 2ημ(α + β)συν(α - β) + ημ(2γ)\]

2: Χρήση της συνθήκης \(α + β + γ = \dfrac{\pi}{2}\)

Από τη δοσμένη συνθήκη έχουμε: \[α + β = \frac{\pi}{2} - γ\]

Επομένως: \[ημ(α + β) = ημ\left(\frac{\pi}{2} - γ\right) = συνγ\]

Επιπλέον, αναπτύσσουμε τον όρο \(ημ(2γ)\) με τον τύπο διπλάσιας γωνίας: \[ημ(2γ) = 2ημγσυνγ\]

Αντικαθιστούμε τα παραπάνω στην παράσταση: \[\text{A.M.} = 2συνγσυν(α - β) + 2ημγσυνγ\]

3: Κοινός παράγοντας

Βγάζουμε κοινό παράγοντα το \(2συνγ\): \[\text{A.M.} = 2συνγ \big[συν(α - β) + ημγ\big]\]

4: Αντικατάσταση του \(ημγ\)

Από τη σχέση \(γ = \dfrac{\pi}{2} - (α + β)\), έχουμε: \[ημγ = ημ\left(\frac{\pi}{2} - (α + β)\right) = συν(α + β)\]

Αντικαθιστούμε μέσα στην αγκύλη: \[\text{A.M.} = 2συνγ \big[συν(α - β) + συν(α + β)\big]\]

5: Υπολογισμός του αθροίσματος συνημιτόνων

Χρησιμοποιούμε τη βασική τριγωνομετρική ταυτότητα για το άθροισμα: \[συν(α + β) + συν(α - β) = 2συνασυνβ\]

(Αναλυτικά: \([συνασυνβ - ημαημβ] + [συνασυνβ + ημαημβ] = 2συνασυνβ\))

6: Τελικό γινόμενο

Αντικαθιστούμε πίσω στην έκφραση: \[\text{A.M.} = 2συνγ \cdot (2συνασυνβ) = 4συνασυνβσυνγ\]

Συμπέρασμα

Αποδείχθηκε ότι: \[ημ(2α) + ημ(2β) + ημ(2γ) = 4συνασυνβσυνγ\]

Ακολουθούν οι υποδείξεις για καθεμία από τις ασκήσεις:

  1. Αν για τις οξείες γωνίες Β και Γ ενός ορθογωνίου τριγώνου \(ΑΒΓ\) ισχύει \(4ημΒσυνΓ = 1\), να αποδείξετε ότι \(Β = 30^o\).

Υπόδειξη

  • Δεδομένα: Ορθογώνιο τρίγωνο με οξείες γωνίες \(B\) και \(\Gamma\), άρα

\(B + \Gamma = 90^\circ \iff \Gamma = 90^\circ - B\), και ισχύει \(4ημ B συν\Gamma = 1\).

  • Βήματα:

    1. Επειδή οι γωνίες είναι συμπληρωματικές, ισχύει \(συν\Gamma = ημ B\).

    2. Αντικαταστήστε στη σχέση: \[4ημ B \cdot ημ B = 1 \iff 4ημ^2 B = 1 \iff ημ^2 B = \frac{1}{4}\]

    3. Επειδή η γωνία \(B\) είναι οξεία (\(0^\circ < B < 90^\circ\)), το \(ημ B\) είναι θετικό: \[ημ B = \frac{1}{2}\]

    4. Από τη βασική τιμή προκύπτει άμεσα ότι \(B = 30^\circ\).

1.4.6 Κατηγορία ΣΤ: Ανισότητες

  1. Να αποδείξετε τις παρακάτω ανισότητες.
  • (i): \(ημα ημβ \le ημ^2\left(\dfrac{α+β}{2}\right)\)

Υπόδειξη

  1. Μετατρέψτε το γινόμενο \(ημαημβ\) σε διαφορά συνημιτόνων: \[ημαημβ = \frac{1}{2}\left[συν(α-β) - συν(α+β)\right]\]

  2. Χρησιμοποιήστε τον τύπο διπλάσιου τόξου \(συν(α+β) = 1 - 2ημ^2\left(\dfrac{α+β}{2}\right)\), οπότε: \[ημ^2\left(\frac{α+β}{2}\right) = \frac{1 - συν(α+β)}{2}\]

  3. Πάρτε τη διαφορά του δεξιού μείον το αριστερό μέλος: \[ημ^2\left(\frac{α+β}{2}\right) - ημαημβ = \frac{1 - συν(α-β)}{2}\]

  4. Επειδή για κάθε γωνία ισχύει \(συν(α-β) \le 1 \iff 1 - συν(α-β) \ge 0\), η ανισότητα αποδεικνύεται.

  • (ii): \(συνασυνβ \le συν^2\left(\dfrac{α+β}{2}\right)\)

Υπόδειξη

  • Ακολουθήστε ακριβώς την ίδια διαδικασία: \[συνασυνβ = \frac{1}{2}\left[συν(α-β) + συν(α+β)\right]\] και αντικαταστήστε \(συν^2\left(\dfrac{α+β}{2}\right) = \dfrac{1 + συν(α+β)}{2}\). Η διαφορά τους δίνει ξανά \(\dfrac{1 - συν(α-β)}{2} \ge 0\).
  • (iii): \(\dfrac{ημα + ημβ}{2} \le ημ\left(\dfrac{α+β}{2}\right)\), για \(α, β \in [0, \pi]\)

Υπόδειξη

  1. Μετατρέψτε το άθροισμα των ημιτόνων σε γινόμενο: \[\frac{ημα + ημβ}{2} = \frac{2ημ\left(\dfrac{α+β}{2}\right)συν\left(\dfrac{α-β}{2}\right)}{2} = ημ\left(\frac{α+β}{2}\right)συν\left(\frac{α-β}{2}\right)\]

  2. Εξετάστε τα πρόσημα:

    • Αφού \(α, β \in [0, \pi]\), έχουμε \(0 \le \dfrac{α+β}{2} \le \pi\), άρα \(ημ\left(\dfrac{α+β}{2}\right) \ge 0\).

    • Γνωρίζουμε ότι για κάθε γωνία ισχύει \(συν\left(\dfrac{α-β}{2}\right) \le 1\).

  3. Πολλαπλασιάζοντας με το μη αρνητικό μέγεθος \(ημ\left(\dfrac{α+β}{2}\right)\), προκύπτει απευθείας το ζητούμενο.

  • (vi): \(\dfrac{συνα + συνβ}{2} \le συν\left(\dfrac{α+β}{2}\right)\), για \(α, β \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]\)

Υπόδειξη

  1. Μετατρέψτε το άθροισμα των συνημιτόνων σε γινόμενο: \[\frac{συνα + συνβ}{2} = συν\left(\frac{α+β}{2}\right)συν\left(\frac{α-β}{2}\right)\]

  2. Επειδή \(α, β \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]\), η μέση τιμή τους ανήκει επίσης στο διάστημα αυτό, δηλαδή \(\dfrac{α+β}{2} \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]\), οπότε \(συν\left(\dfrac{α+β}{2}\right) \ge 0\).

  3. Επειδή \(συν\left(\dfrac{α-β}{2}\right) \le 1\), πολλαπλασιάζοντας με το μη αρνητικό \(συν\left(\dfrac{α+β}{2}\right)\) ολοκληρώνεται η απόδειξη.

3.1 ΘΕΜΑ Α

  • Α1.2: Θέτουμε \(A = α + β\) και \(B = α - β\).

    Προσθέτοντας και αφαιρώντας κατά μέλη τις δύο αυτές σχέσεις, λαμβάνουμε: \[α = \frac{A + B}{2} \quad \text{και} \quad β = \frac{A - B}{2}\]

    Αντικαθιστώντας τα \(α\) και \(β\) στον τύπο \(2ημασυνβ = ημ(α + β) + ημ(α - β)\), προκύπτει: \[\mathbf{ημ A + ημ B = 2ημ\left(\frac{A+B}{2}\right)συν\left(\frac{A-B}{2}\right)}\]

3.2 ΘΕΜΑ Β

    \[A = συν 105^\circ + συν 15^\circ = 2συν\left(\frac{105^\circ + 15^\circ}{2}\right)συν\left(\frac{105^\circ - 15^\circ}{2}\right)\]

    \[= 2συν 60^\circ \cdot συν 45^\circ = 2 \cdot \frac{1}{2} \cdot \frac{\sqrt{2}}{2} = \mathbf{\frac{\sqrt{2}}{2}}\]

  • Β1.2: Εφαρμόζουμε τον τύπο μετατροπής γινομένου ημιτόνων σε άθροισμα:

    \[B = ημ 75^\circ \cdot ημ 15^\circ = \frac{1}{2}\left[συν(75^\circ - 15^\circ) - συν(75^\circ + 15^\circ)\right]\]

    \[= \frac{1}{2}\left(συν 60^\circ - συν 90^\circ\right) = \frac{1}{2}\left(\frac{1}{2} - 0\right) = \mathbf{\frac{1}{4}}\]

  • Β2.1: Γράφουμε το \(1\) ως \(ημ 90^\circ\) (ή \(ημ\dfrac{\pi}{2}\)):

  • Β2.2: Ομαδοποιούμε τον πρώτο και τον δεύτερο όρο: \[\Delta = (ημ(5x) + ημ(3x)) + 2ημ(4x) = 2ημ(4x)συν x + 2ημ(4x)\]

3.3 ΘΕΜΑ Γ

    • Αριθμητής: \[(ημ(5x) + ημ x) + ημ(3x) = 2ημ(3x)συν(2x) + ημ(3x) = ημ(3x)(2συν(2x) + 1)\]

    • Παρονομαστής: \[(συν(5x) + συν x) + συν(3x) = 2συν(3x)συν(2x) + συν(3x) = συν(3x)(2συν(2x) + 1)\]

    Συνθέτουμε το κλάσμα: \[\frac{ημ(3x)(2συν(2x) + 1)}{συν(3x)(2συν(2x) + 1)} = \frac{ημ(3x)}{συν(3x)} = \mathbf{εφ(3x)}\]

  • Γ2: Πολλαπλασιάζουμε και τα δύο μέλη της εξίσωσης με το \(2\):

    \[2ημ(3x)συν x = 2ημ(4x)συν(2x)\]

    Εφαρμόζουμε τους τύπους μετατροπής γινομένου σε άθροισμα:

    \[ημ(3x + x) + ημ(3x - x) = ημ(4x + 2x) + ημ(4x - 2x)\]

    \[ημ(4x) + ημ(2x) = ημ(6x) + ημ(2x) \iff ημ(6x) - ημ(4x) = 0\]

    Μετατρέπουμε τη διαφορά ημιτόνων σε γινόμενο:

    \[2ημ\left(\frac{6x - 4x}{2}\right)συν\left(\frac{6x + 4x}{2}\right) = 0 \iff 2ημ x συν(5x) = 0\]

    • Από \(ημ x = 0 \iff \mathbf{x = k\pi}, \ k \in \mathbb{Z}\).

    • Από \(συν(5x) = 0 \iff 5x = k\pi + \dfrac{\pi}{2} \iff \mathbf{x = \dfrac{k\pi}{5} + \dfrac{\pi}{10}}, \ k \in \mathbb{Z}\).

3.4 ΘΕΜΑ Δ

  • Δ1: Ομαδοποιούμε τον πρώτο και τον τρίτο όρο της εξίσωσης:

    \[(ημ(5x) + ημ x) + ημ(3x) = 0\]

    Μετατρέπουμε το άθροισμα σε γινόμενο:

    \[2ημ(3x)συν(2x) + ημ(3x) = 0 \iff ημ(3x)(2συν(2x) + 1) = 0\]

    • 1η περίπτωση: \[ημ(3x) = 0 \iff 3x = k\pi \iff \mathbf{x = \frac{k\pi}{3}}, \ k \in \mathbb{Z}\]

    • 2η περίπτωση: \[2συν(2x) + 1 = 0 \iff συν(2x) = -\frac{1}{2} = συν\left(\frac{2\pi}{3}\right)\] \[2x = 2k\pi \pm \frac{2\pi}{3} \iff \mathbf{x = k\pi \pm \frac{\pi}{3}}, \ k \in \mathbb{Z}\]

  • Δ2: Σε κάθε τρίγωνο ισχύει \(A + B + C = \pi \iff A + B = \pi - C\), οπότε: \[ημ(A + B) = ημ(\pi - C) = ημ C \quad \text{και} \quad συν(A + B) = συν(\pi - C) = -συν C\]

    Εφαρμόζουμε τον μετασχηματισμό αθροίσματος στους δύο πρώτους όρους του αριστερού μέλους:

    \[ημ(2A) + ημ(2B) + ημ(2C) = 2ημ(A + B)συν(A - B) + 2ημ C συν C\] \[= 2ημ C συν(A - B) + 2ημ C συν C\] \[= 2ημ C \left[συν(A - B) + συν C\right]\]

    Αντικαθιστούμε το \(συν C\) με το \(-συν(A + B)\): \[= 2ημ C \left[συν(A - B) - συν(A + B)\right]\]

    Εφαρμόζουμε τον τύπο μετατροπής διαφοράς συνημιτόνων σε γινόμενο \(συν X - συν Y = -2ημ\left(\dfrac{X+Y}{2}\right)ημ\left(\dfrac{X-Y}{2}\right)\): \[συν(A - B) - συν(A + B) = 2ημ A ημ B\]

    Άρα: \[2ημ C \cdot (2ημ A ημ B) = \mathbf{4ημ A \cdot ημ B \cdot ημ C}\]
